# Financial Performance Analysis of FMCG Companies

## Overview
A comparative financial analysis of five FMCG companies over six years, examining their growth, profitability, liquidity, financial leverage, and asset efficiency using financial ratios.

## Companies
- ITC
- Hindustan Unilever (HUL)
- Britannia Industries
- Marico
- Nestlé India

## Tools Used
- **Microsoft Excel:** Data organisation and ratio calculations
- **Python:** Data analysis
- **Pandas:** Data processing
- **Matplotlib:** Data visualisation

## Key Findings
- **Marico:** Highest average revenue growth
- **ITC:** Highest average net profit margin and current ratio
- **Nestlé India:** Highest average ROA, ROE, and asset turnover
- **Britannia:** Highest average Debt-to-Equity Ratio
